# Native EPUB Kit documentation

These guides describe the supported Native EPUB Kit 0.x community release
candidate. They ship inside the npm package and cover the headless SDK without
assuming a particular catalog, database, theme, or brand. Product chrome,
storage selection, sharing design, networking, and rights policy remain
consumer-owned.

1. [Install and open a local EPUB](getting-started.md)
2. [Core view, events, commands, and errors](core-api.md)
3. [Complete generated API reference](api-reference.md)
4. [Product integration patterns](product-integration.md)
5. [Task-oriented recipes](recipes.md)
6. [Troubleshooting](troubleshooting.md)
7. [0.x alpha migration](alpha-migration.md)
8. [Known limitations and native upgrades](limitations-and-upgrades.md)

The typechecked examples under [`examples/`](examples/) are the sources for
marked README doctests. The repository's deeper architecture records explain
invariants and qualification evidence. These bundled guides are the shortest
supported path from a clean Expo application to the same APIs.

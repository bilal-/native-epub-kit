# Qualification font

`LateefQualification.ttf` is the unmodified Lateef 400 Regular font used only
to qualify app-supplied font delivery into Readium's native WebViews.

- Family/version: Lateef v35, 400 Regular
- Upstream distribution: Google Fonts / `@expo-google-fonts/lateef` 0.4.2
- Upstream file URL:
  `https://fonts.gstatic.com/s/lateef/v35/hESw6XVnNCxEvkbMpheEZo_H_w.ttf`
- SHA-256:
  `24e3f78cbc0bcf7d8e63552712fdcc165ccad30771c4fd6842cb4089a70e74f7`
- Copyright: Copyright 1994–2025 SIL Global; Latin glyphs copyright 2018
  The Crimson Pro Project Authors
- License: SIL Open Font License 1.1 (`OFL-1.1`)

The complete upstream license is retained in `Lateef-OFL-1.1.txt` (SHA-256
`63fbda065921d34b9421154fbdeba09075efa2405a5bcb32fbbcfd0aeea892c9`).
The reference webBooks app uses Lateef for Arabic text, but these files were
selected from the independently licensed Google Fonts package; its custom Urdu
and Quranic font files were not copied because their redistribution terms have
not yet been verified.

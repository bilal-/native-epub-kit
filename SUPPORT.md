# Support

Native EPUB Kit is pre-1.0 software. Community support is best effort; there is
no service-level or long-term-stability guarantee. Published versions follow
semantic versioning, and the exact supported toolchain is recorded in the
compatibility matrix.

Use GitHub Issues for:

- Reproducible bugs in the public package or example.
- Documentation defects.
- Focused feature proposals that fit a headless native EPUB SDK.

Before filing, search existing issues and test the latest supported revision.
Include a minimal public EPUB when content is required to reproduce a reader
problem. Never attach restricted books, proprietary fonts, credentials, or
personal reading data.

Include package integrity, Expo/React Native versions, platform/toolchain,
stable error code/phase, and the redaction-safe SDK diagnostic report. First
reproduce against a clean Expo consumer when possible. See the bundled
troubleshooting guide before opening an issue.

Questions about an application's catalog, persistence, branded UI, accounts,
or downloads belong to that application rather than this library.
Security and conduct reports must follow [SECURITY.md](SECURITY.md) and
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md), not public issues.
